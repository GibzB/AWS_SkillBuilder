# 30 Days of AWS News: Progress Checklist

Campaign: `aws-news-30` ("30 Days of AWS News")

> 🔥 **Current posting streak: Day 0** — publish a day to start a fresh chain at 🔥 Streak Day 1.

Three stages per day:

- **S3**: article generated, validated, and published to S3/CloudFront (automated).
- **BC draft**: filled into the Builder Center editor (title/description/body + auto-tags) via the assisted tool.
- **BC published**: you clicked Publish on Builder Center (live post).
- **Streak**: consecutive-posting counter for the 30 daily rows. 🔥 N = Nth day of the unbroken chain; `· broken` = not published yet.
- **W rows**: the Sunday weekly roundups. They are tracked separately and never change the daily streak or the banner.

Notes hold the AWS service and the announcement date once a day has been drafted.

Command to draft a day:

```
scripts/run.sh publish --news --from N --to N --auto-tags
```

Command to draft a weekly roundup:

```
scripts/run.sh publish --news --week N --auto-tags
```
